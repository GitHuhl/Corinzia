Corinzia for Windows (x86-64)
=============================

Unzip anywhere and run corinzia.exe. Keep the "fonts" folder next to it:
the score's text and the interface use the fonts in it.

* Audio goes to the default output device (WASAPI).
* CLAP instruments are found in the standard places:
  %LOCALAPPDATA%\Programs\Common\CLAP and %COMMONPROGRAMFILES%\CLAP
  (and in the folders listed in the CLAP_PATH environment variable).
* Needs Windows 10 or 11 with a DirectX 12 or Vulkan capable graphics driver.

Projects are saved as .project files (SQLite). Export writes PDF, MIDI and
MusicXML.

Report problems at https://github.com/GitHuhl/Corinzia/issues
